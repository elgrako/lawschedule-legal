# LawSchedule — Páginas legales

Páginas estáticas de política de privacidad y eliminación de datos para la app **LawSchedule**, publicadas para cumplir con los requisitos de las tiendas de aplicaciones (Google Play) y la normativa de protección de datos.

## Contenido

| Archivo | Contenido |
|---|---|
| `index.html` | Política de privacidad |
| `eliminacion_datos.html` | Instrucciones para solicitar la eliminación de datos y de la cuenta |

## Uso

Son páginas HTML estáticas, sin dependencias ni backend. Se publican tal cual (por ejemplo, con GitHub Pages) y se enlazan desde la ficha de la app en la tienda correspondiente.
